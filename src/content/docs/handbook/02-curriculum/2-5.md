实际上，如你已经可以在前文中见到的，课纲设计中的共读人导向早已体现在包括文本阅读、问题设计、游戏互动设计等在内的诸多环节。但是我们依然希望单独拿出这样一个章节来尤其说明，在开课之前你能做的所有筹备工作中，共读人的导向还应当在哪些方面体现。

### 2.5.1 推送宣传文案与共读人版课纲中的语言选择

知合推送中的宣传文案和共读人版课纲主要用于线上招生环节，让知合潜在的共读人群体对你的课程产生报名的兴趣。一般情况下，品牌组不会对你提供的内容做出直接的审核与修改，但作为领读人，你也需要思考如何让文案对共读人来说可读性更强、更有吸引力。
- 你需要避免的是：
  - 全篇过于学术化或专业化的语言表达（eg. 堆砌术语、黑话自嗨）
  - 封闭式或引导性过强的问题（eg. “你是否同意.……”）
  - 权威性或说教式的语气（eg. “共读人有必要意识到XX议题的重要性”）
  - 忽视参与者的多样性（eg. “只专注某一类人群，我们只讨论XX问题”）
  - 抽象或空洞的语言（eg. “XX具有深层含义和重要价值”）
- 我们更加推荐你：
  - 使用通俗易懂、生活化的语言
  - 可以贴近共读人的生活经验（eg. 学校、家庭、职场、情感等主题，引发共鸣）
  - 真实故事或社会热点或事件
  - 比较有争议性或有开放空间探讨的社会议题与学科视角

- 介绍自己读书会的创新点（eg. 多媒介材料的使用、多学科视角）
  - 可以检阅自己的文案措辞是否满足以下特点：可读性、多元视角、包容性、趣味性以下两个往期课程的推送文案供你参考：
没有人会永远是世界的多数派。当我们面对少数派，或者当我们就是少数派时，我们要如何去面对这种多与少的力量对比造成的张力？以及这个日益复杂且多元的世界？并且自从19世纪以来，中美大规模接触已经超过一百多年，然而在中国社会中对美国的理解始终带有着浓厚的实用主义与意识形态色彩。
在这一课题中，我们将以美国历史上的少数群体为切入口，亲自进入他们的历史世界。本课题力图避免落入过度学理化的窠臼，除了阅读之外将会有非常多不同的讨论形式，在这一课题中，我们将一起开展对巫师的审判，参与黑人领袖的相互辩论，尝试写一部你自己的宣言书……希望在这一过程中我们能够理解社会的复杂性与多元性，以及历史上的少数群体对于现代世界的意义。同时，希望能够使同学们在阅读历史文献的过程中，形成对于历史以及当下社会独特的、具有自我意识的理解，最终能够通过本课题不仅了解美国历史，同时借助美国这一面镜子，对于自身所处社会也能形成不一样的观察视角与理解。
@张皓盟《美国历史上的少数派》
你会不会感觉学校压抑了你的活力？你对爱情的想象（或现实），有没有一种是坐在食堂里，面对面吃饭？打游戏可能成为你

与家长的沟通方式吗？个体的生活与失序的社会之间，会以怎样的方式进行关联？今天的诗歌可以怎样处理、转化生命中的痛苦？
五天的读书会里，我们将借助一系列青年文学作品对以上话题展开探索。它们既涵盖小说、散文、诗歌等传统文体，也有媒体特稿、非虚构写作等新形式，中文书写则是它们回应当下年轻人困境的共同方式。通过一起阅读、思考、想象和讨论，我们既能增加一面理解自身的镜子，也可以了解文学如何处理生活，相对影视、社科等领域，又有哪些特别之处。以及，如果你想写点东西，这些作品和相关讨论或许也能提供参考！
@王翰乾《你我的文学：共读中国当代青年文学》

### 2.5.2 提前收集共读人信息并灵活调整课程内容

- 通过招生报名问卷信息了解共读人各营地的招生负责人会及时更新共读人的报名信息，这里领读人可以提前获知的是性别比例、年龄分布、院校和专业的背景情况，并需要提前考虑这些不同的身份群体特点可能对于特定主题的圆桌开展造成的影响（相应的应对方式可参见3.4.2。
- 通过开课前的自制问卷信息了解共读人除了这些基本信息之外，我们也建议你在开课前拉起课程群，并自制问卷收集共读人对于本次课程的期待。为了方便共读人填写，大部分问题可以以选择题为主，并且不设置必做题。以下问题供你参考：
  - 你希望通过本次共读获得的最大收获是什么？（根据课程内容给出不同选项及其他项）
  - 目前来说你最期待的是哪节课？（选项放每节课的序号和主题）

- 你更喜欢哪种形式的课堂活动？（a.共读完各自分享观点 / b.小组讨论 / c.角色扮演或模拟活动 / d.绘画、艺术创作等创意活动 / e.学术文献阅读与分析 / f.辩论 / g.其他）
  - 你是否有其他需求或建议希望我了解？
  - 特别地，在理论偏硬核的课程，了解共读人的基础知识水平是尤为必要的。然而收集这类信息时，问卷的题目应当避免出现“您对本次共读主题的了解程度是？A.完全不了解  B.了解一些基本概念  C.有一定的经验和实践  D.非常熟悉”这样较为宽泛的问题，而是将问题具体化。例如，可以列举一些课堂上一定会涉及的关键词，让大家来评估一下对这些词的熟悉程度；或是拎出一些领域内很有争议的命题，先让大家站站队（当然也可以选：我不知道这个观点什么意思），这样也更方便圆桌上组织激烈的讨论

- 通过每日课后问卷了解共读人为了使得课程更好地适应共读人的基本状况，在每节课（尤其是第一节课）课后，我们也鼓励你再次制作（匿名）调查问卷并由此作为调整后续课节的参考，问卷的内容可以包括但不限于：
  - 今天文本材料的阅读难度是否恰当（适合/我需要更深度/更简单一点的材料）
  - 今天阅读材料的时长是否接受（接收/不接受）（可写自己的建议，例如给的时间过短/过长）
  - 今天有没有让自己感到不舒适的时候？（跳过/描述原因）
  - 之后课堂希望有何调整/建议（无/建议）
  - 如果希望与领读人单独约聊/约饭，可以留下姓名与期待的时间
